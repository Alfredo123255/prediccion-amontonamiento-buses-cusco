## Agent skills

### Issue tracker

Markdown local en `.scratch/<feature>/` (spec en `spec.md`, tickets en `issues/NN-<slug>.md`). See `docs/agents/issue-tracker.md`.

### Triage labels

Las cinco etiquetas por defecto (`needs-triage`, `needs-info`, `ready-for-agent`, `ready-for-human`, `wontfix`) como línea `Status:` en cada archivo. See `docs/agents/triage-labels.md`.

### Domain docs

Single-context: `GLOSSARY.md` y `docs/adr/` en la raíz (se crean al necesitarse). See `docs/agents/domain.md`.
